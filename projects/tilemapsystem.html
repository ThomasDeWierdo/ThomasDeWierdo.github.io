Tilemap System

Tilemap

 This system shows knowledge on optimization and shows how I can reduce the amount of repetitive tasks needed to implement new features.

Overview

 The tilemap system is in charge of rendering your world into visible blocks. Unity has a built-in tilemap system, but it would lag a lot when modifying tiles at runtime so I decided to create my own system. If you didn't look at the description of Perastra, it is the game I made this system for as it has a 2D pixelated grid-based sandbox world. The world is split up into 16x16 chunks of blocks, so all this system has to do is read the current data of a given chunk, then create a mesh that correctly renders all the individual blocks of that chunk. There is also an autotiling system that makes it so the same blocks can use slightly different textures to make it visually appear that blocks are connected and flow correctly with the surrounding blocks.
